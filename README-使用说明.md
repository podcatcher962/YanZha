# 言札 · 使用说明

把录音、播客、会议、视频，变成能直接用的文字稿。
**不上传、不联网、不要账号、不限时长、不花钱。**

---

## 这一版新增（0.6.0）

- **亮色主题**：顶栏「☀ 亮色 / ☾ 暗色」一点就换，选择记在本机，下次打开照旧。
  暗色里偏灰的时间码、状态行也一起提亮了
- **语种默认锁中文**：中文录音在底噪、笑声重的段落偶尔会冒出日文、韩文，现在会被清掉；
  录的是外语或中英日混说，把左下角「语种」切到「自动 · 中英日韩粤」
- **人数**：知道自己录的是几个人（1~6，1 就是单人）就选上，按人数分人比自动判准得多；
  已经转好的稿子改人数再点「开始转写」，只重跑分人，几秒就好
- **小声的录音更准**：手机录得偏小的文件，会先抬到正常音量再识别；本来够响的不动

## 怎么用

1. **双击 `YanZha.exe`**
2. 点「添加音视频文件」，选一个或一批文件
3. 点「开始转写」，等进度条走完
4. 点左边转好的文件，右边就是稿子；按需要「导出」
5. 同一批录音老在那几个词上出错？右上角「术语表」填两栏（左＝错的词，右＝改成什么），往后每期自动改（见下面）

> 一小时录音，大约三分钟转完（普通笔记本，不插电也能跑）。
> 勾了「区分说话人」再多花半分钟左右，不再翻倍。

---

## 支持的文件

**音频**：mp3 / m4a / wav / flac / aac / ogg / opus / wma
**视频**：mp4 / mkv / mov / avi / flv / webm / ts / m4v

视频会先把声音抽出来再转，不用另外转码。

## 校对：边听边改

机器听出来的稿子总要顺一遍，所以这一步做进了软件里：

- **双击任意一句**（或点时间码）→ 从这句开始播原音，边听边改
- 鼠标移到句子上，右侧出现 **「改」** → 点它就地改字，**回车保存、Esc 取消**
- 那句是噪声或语气词？**把字清空再回车 = 删掉这一句**，导出的稿子里就没有了
- 改错了按 **`Ctrl+Z`** 撤销，可以一路退回去
- 顶部有个搜索框，输个错字按回车，**自动跳到下一处**；命中句会标灰底
- 同一个错字满篇都是？点搜索框右边的**「替」**，填上正确的词 →**「全部替换」**，一次改完；
  按 `Ctrl+Z` **整批退回**（几百句也是一次退完）。替换框**留空**＝把这几个字删掉，
  删完只剩标点的句子会整句去掉

**导出前会自动扫一遍**，只挑**根本没人说过的**东西：只剩标点的空壳句、把「（音乐）（掌声）」写进正文的行、
同一段被识别两遍（两句时间戳重叠才算）。

**句子长短、口吃、拖音、一个词连说三遍、绕回来又讲一遍，全都是原声，一个字都不提醒你改。**
这是言札的底线：稿子要能证明「他当时就是这么说的」。

**只是提醒，不改也能照样导出**；一句问题都没有时不弹窗，底部会显示「扫过一遍，没发现问题」。

改完不用重新导出草稿——`txt / md / Word / srt / vtt / json` 用的都是改后的文字。

## 术语表：错一次，以后都不用手改

同一个主播的人名、栏目名、书名、公司名，每一期都会错成同一个样子。
每期都去搜索框改一遍，改的其实是同一批词。

点右上角 **「术语表」**，弹出来是**左右两栏**，填就行：

| 转写里出现 | → | 改成 |
|---|---|---|
| 李蛋 | → | 李诞 |
| 阿里巴巴 | → | 阿里巴巴集团 |
| 嗯嗯 | → | （留空） |

- **不用敲箭头**（键盘上没有 `→`）——左栏打错的词，右栏打对的字，中间那个箭头是画给你看的
- **右栏留空 = 把这个词删掉**（口语里的「嗯嗯」「那个那个」就这么去掉）
- 左栏打完按回车跳到右栏，右栏按回车自动加一条；点每行右边的 `×` 删掉这一条
- 从别处复制一整行 `李蛋→李诞` 粘到左栏，会自动拆进两栏
- 默认**转完自动套用**，列表里会写「术语 3 处」；改错了 `Ctrl+Z` **整批退回**
- 更省事的写法：在稿子上用**「替」**改对之后，勾上替换条里的**「记住」**，这条替换就自动进术语表了，不用回弹窗再打一遍
- 不想自动改就去掉那个勾，之后在「导出」菜单里点 **「按术语表改一遍」**

术语表只做你自己声明的替换，软件不会自己猜哪个字该改。

## 稿子不会丢

转完、改完，程序都会在本机存一份草稿。**改到一半直接关程序也不丢。**

- 下次打开，左栏出现「有 N 份没导出的稿子」，点一下就能接着改
- 草稿存在 `%LOCALAPPDATA%\YanZha\drafts`，**不上传、也不放进你的源文件夹**
- 导出过的稿子不再提醒；也可以在那份列表里点「删」自己清掉
- 源文件被移走了也能打开草稿——只是不能听原音、不能重跑分人

---

## 区分说话人

多人播客、访谈、对谈，勾上左下角的 **「区分说话人」**，
稿子会按人分段，标成「说话人 1 / 2 / 3 …」。

- **单人录音勾了也没关系**：只分出一个人时，标注会自动去掉，
  导出的就是干干净净的稿子，多花的只是几十秒分析时间
- 默认是开着的；确定是单人朗读、讲座，关掉更快
- 分几人不影响文字本身，只影响分段和标注
- 左下角 **「人数」** 默认自动。自动分人最常出的错是「明明四五个人，只分出两个」——远场录音里不同人的声纹会互相靠拢，硬阈值一裁就裁掉了。你清楚知道自己录的是几个人，就选上（1 到 6 人，**1 就是单人**），**按人数硬分，比任何自动判据都准**。
  自动分出 4 人以上时，稿子上方会直接问「这段其实几个人」，点「只有 1 个人」或「是 2 人」就重分，不用自己去找那个下拉框
- 分人的取舍是**宁可多分一个人，也不把两个人糊成一个**：糊在一起改不回来，重跑一遍还是糊的；多出来的人点一下就能改名
- 声音重叠、抢话、笑声多的时候，分人仍然可能有偏差，这是这类技术的通病；这时指定人数比自动稳得多

## 导出的八种格式

| 格式 | 用途 |
|---|---|
| **纯文本 .txt** | 按段落整理好的稿子，直接复制到别处 |
| **Markdown .md** | 带标题，适合放进笔记软件 |
| **Word .docx** | 能直接打开改，交给别人也方便 |
| **字幕 .srt** | 每一句带起止时间，导入剪映、Premiere、B 站；一句太长会自动折成两行，屏幕不溢 |
| **字幕 .vtt** | 网页播放器、YouTube 用的字幕格式；同样自动折行 |
| **带时间戳 .txt** | 每行前面有 `[00:12:34]`，方便回听核对 |
| **结构化 .json** | 每句的起止时间、文字、说话人，给程序或脚本用 |
| **校对稿 .txt** | 一行一句、行首带编号，专门拿去外面改，改完能粘回来（见下） |

**想把稿子拿出去改？** 点「导出 → 校对稿」存一个 txt，一行一句、行首是编号。
拿给任何工具改（本程序不联网，稿子出不出这台电脑由你决定），改完点「导出 → 粘贴改好的稿子…」，
把整篇贴进去：按编号逐句落回，**时间戳和说话人都留着**，一次 `Ctrl+Z` 全退回。
编号弄丢的那几行会跳过并告诉你，其余照常回填；说话人那一列改了不生效，要改名到稿子左边点「改名」。

**一次转了一批文件，不用一份一份导**：点「导出」→**「全部导出到文件夹…」**，
选一个文件夹，所有转好的稿子按同一种格式一起写进去。撞上同名文件不会覆盖，自动加 `-2`。

## 常见问题

**转出来的字有错怎么办？**
先看是不是录音质量问题（远场、回声、背景音重）。稿子可以直接编辑，遇到错字改掉就行。人名、数字、专业词最容易错，重要内容请人工核对。

**能转哪些语言？**
中文、English、日本語、한국어、粤语，不用手动选，模型自己判断语种；一段里中英混说也认。
普通话最准。四川话、天津话这类方言能认出大意，但不保证每个字都对。

**中英混着说呢？**
可以。英文会保留空格，和中文分开。

**为什么这么快？**
识别模型就在本地，用的是 CPU，不是云。你的电脑几核它就用几分力。

**文件特别大（两小时以上）？**
可以转，只是要多等一会儿。进度条是实时的，随时能停。

**要不要显卡？**
不要。纯 CPU，核显也能跑。

**出错了我该做什么？**
日志在 `%LOCALAPPDATA%\YanZha\yanzha.log`，把它发给作者就能定位问题。

**改了「区分说话人」的勾选，要重新转一遍吗？**
不用重转。识别结果会留着，只重跑分人那一步，几十秒就好。

**改了勾选后点「开始转写」没反应？**
已经转好、参数又没变的文件不会重复跑。换勾选或者换文件才会动。

## 目录说明

```
YanZha.exe        主程序
ffmpeg.exe        音频解码（79 MB）
models/           模型（256 MB，不要删）
  asr/            识别（SenseVoice，中英日韩粤，自带标点）
  vad/            语音检测
  speaker/        说话人声纹
LICENSE           MIT 许可证
```

**不要只把 exe 单独拷出来**，它要靠同目录的 `models` 才能启动。

体积主要是模型：识别 228 MB、认人 27 MB。
v0.2.0 换成 SenseVoice 之后，一个模型顶掉原来「识别 + 标点」两套，包反而小了 81 MB，
还多了日、韩、粤和英文——换来的是一小时录音约三分钟出稿、全程不联网。
