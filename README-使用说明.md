# 言札 · 使用说明

把录音、播客、会议、视频，变成能直接用的文字稿。
**不上传、不联网、不要账号、不限时长、不花钱。**

---

## 这一版新增（0.7.2）

- **视频自带字幕，直接导成文字稿（0.7.2 新）**：很多视频里带一条独立的字幕流（播放器里能开关的那种），
  文字是现成的。文件加进列表后，那一行会多出一个 **「字幕」** 小键，点一下就把字幕导出来 ——
  不跑识别、不用等，**一个字都不会错**。SRT / ASS / SSA / WebVTT / MP4 内嵌字幕都认
- **字幕和识别只留一份（0.7.2 新）**：字幕本来就是照着台词做的，跟识别出来的内容讲的是同一段话，
  所以导入是**整份替换**，不会两份并排。已经转过的文件想改用字幕，同样点那个小键，
  会先问一句「整份替换、手改的不保留」；文本字幕有多条时（中英双语之类）会让你选用哪一条
- **图片字幕会明说（0.7.2 新）**：蓝光 PGS、DVD VobSub 里的字幕存的是图片不是字，
  点了不会假装成功，直接提示「得靠识别」
- **撤销有了按钮（0.7.1 新）**：稿子右上角 **「↺ 撤销」**，改过之后才亮，灰着就是没得退。
  点一下退一步，`Ctrl+Z` 照样能用。改字、删句、换人、断句、并句、整组改名**都在同一个撤销里**，最多退 300 步。
  注意：**关掉软件撤销记录就清空**，改坏了先别关窗口
- **导出前会问一句（0.7.1 新）**：手动改过之后再点导出，先问「这些改动要带进文件吗」。
  选 **「用原始稿导出」**，稿子还原成刚转写出来的样子，误点出来的改动一点不留
- **整组改名也能撤了（0.7.1 新）**：以前点小标题改名退不回来，现在跟别的改动一样能退
- **长句的最后几个字不再被按钮压住（0.7.1 新）**：句子右侧留出了按钮的位置
- **单句换人（0.7.0）**：鼠标移到任意一句，右下角出现「讲1 改 断 并」。点前面那个小标就是「这一句是谁说的」，点一下就换，也可以现写「主持人」「嘉宾」；**只动这一句**，同一组里别的句子不动。整组改名还是点稿子左边的小标题
- **断句（0.7.0 新）**：一句里其实是两个人在抢话？点「断」，把光标放到要分开的地方，弹窗里实时显示两半的字数和时间，后半句还能顺手指定给另一个人，点「切开」就分成两句。时间按字数比例插值，字幕会有半秒上下偏差
- **并句（0.7.0 新）**：识别器把一句话切碎了（「前半句，」「后半句。」），点「并」和下一句接起来；两句不同人时按前一句算，状态栏会说明
- **读音校对（0.6.2）**：只知道名字「正确」怎么写、不知道模型写成了什么，右上角「读音校对」只写对的，一行一个，软件按拼音把读音对得上、字不一样的地方列出来，逐条勾选才改。不勾就一个字都不动（详细用法见下面「读音校对」一节）
- **分多了会问一句（0.6.1 新）**：自动模式分出 4 人以上时，稿子上方直接问「其实几个人」，点一下只重跑分人，手改过的字不动；人数下拉补了「1 人（单人）」
- **稿子能拿出去改再粘回来（0.6.1 新）**：「导出 → 校对稿」存成一行一句、带编号的 txt，拿给任何工具改；改完「导出 → 粘贴改好的稿子」贴回来，按编号逐句落回，时间轴和说话人都留着
- **亮色主题**：顶栏「☀ 亮色 / ☾ 暗色」一点就换，选择记在本机，下次打开照旧。
  暗色里偏灰的时间码、状态行也一起提亮了
- **语种默认锁中文**：中文录音在底噪、笑声重的段落偶尔会冒出日文、韩文，现在会被清掉；
  录的是外语或中英日混说，把左下角「语种」切到「自动 · 中英日韩粤」
- **人数**：知道自己录的是几个人（1~6，1 就是单人）就选上，按人数分人比自动判准得多；
  已经转好的稿子改人数再点「开始转写」，只重跑分人，几秒就好
- **小声的录音更准**：手机录得偏小的文件，会先抬到正常音量再识别；本来够响的不动

## 怎么用

1. **双击 `YanZha.exe`**
2. 点「添加音视频文件」，选一个或一批文件
3. 点「开始转写」，等进度条走完
4. 点左边转好的文件，右边就是稿子；按需要「导出」
5. 同一批录音老在那几个词上出错？右上角「术语表」填两栏（左＝错的词，右＝改成什么），往后每期自动改（见下面）

> 一小时录音，大约三分钟转完（普通笔记本，不插电也能跑）。
> 勾了「区分说话人」再多花半分钟左右，不再翻倍。

## 支持的文件

**音频**：mp3 / m4a / wav / flac / aac / ogg / opus / wma
**视频**：mp4 / mkv / mov / avi / flv / webm / ts / m4v

视频会先把声音抽出来再转，不用另外转码。

## 视频里本来就有字幕

有些视频（网课、录屏、压好的影视）本来就带字幕，就是播放器里能开关的那种。
那是现成的文字，不用识别。

1. 把视频加进列表
2. 那一行会多出一个 **「字幕」** 小键（还没转写的、已经转过的都有）
3. 点它 —— 只有一条字幕轨就直接导，有多条会让你选（中文片挂英文字幕的很常见，默认第 1 条不一定对）
4. 导进来的稿子和识别出来的完全一样用：能改字、能换人、能断句并句、能撤销，八种导出格式都行

**两件事要知道**：

- 字幕**不标谁在说话**，说话人一栏是空的。需要的话点句尾的「讲1」自己补
- 蓝光 / DVD 那种字幕存的是**图片**，导不出来，点了会提示你改用识别

不跑模型，几秒就完，跟转写一小时录音不是一个量级。

## 改 · 断 · 并：先认情况，再动手

鼠标移到任意一句上，那句话的**右下角**会浮出四个小键：**讲1　改　断　并**。
鼠标移开就收起来，不挡着读稿。点错了也不要紧，右上角都能退回来。

| 你看到的情况 | 点哪个 | 结果 |
|---|---|---|
| 有个字听错了 | **改** | 原地改，**回车**保存、**Esc** 不改 |
| 整句是「嗯」「啊」「（笑）」这类 | **改** | 把字全删掉，回车 = 删掉这一句 |
| 一句话里其实是两个人在说（抢话、接话被识别成一句） | **断** | 切成两句，各归各人 |
| 一句话被切成两半（上一句以「，」收尾，下一句接着往下说） | **并** | 和下一句接回去 |
| 字没错，人错了 | **讲1** | 只改这一句的说话人，同组别的句子不动 |
| 整组人的名字都不对（一直是「说话人 2」，其实是嘉宾） | 稿子左边的**小标题** | 整组改名 |

### 「断」怎么断：三步

1. 点那句的 **「断」**，整句摊在框里
2. 把光标放到**两个人分界的地方**——比如「…这样啊。那我说两句」的「那」前面。
   下面立刻显示「前 12 字（00:05 → 00:08）　后 15 字（00:08 → 00:12）」，一眼看出切在哪
3. 顺手在「后半句是谁」里选个人（不选就跟前面同一个人），点 **「切开」**

先切开、再点「讲1」换人，结果一样，只是多一步。切点离两头太近会被拦下——两边至少要留一个字。

### 「并」什么时候用

识别器把一口气的话断成两句时用：上一句以逗号收尾、下一句接得很顺，就像「前半句，」和「后半句。」这两行。

两句不是同一个人时**按前一句算**，状态栏会写出来；觉得分错了按 `Ctrl+Z` 退回，再用「断」重新切。

### 断句的时间为什么差零点几秒

稿子里只有「这一句从 00:05 到 00:08」，**没有每个字的时间**，声纹也只在整句上有一份。
所以切开时按**字数比例**分时间：前半占 40% 的字，就分 40% 的时长。

字幕可能差零点几秒——但比整句归错人强。要精确到字，得重新转写并开逐字时间戳，本版不做。

### 改错了怎么回来

- 点右上角 **「↺ 撤销」**，或按 `Ctrl+Z`：一步一退，可以连退（最多 300 步）
- 改字、删句、换人、断句、并句、整组改名，都在**同一个撤销**里，混着改也能按顺序退
- **关掉程序就撤不回去了**（撤销记录只在内存里）——改坏了先别关窗口
- 已经关掉才发现改乱？导出时会先问你一句，选 **「用原始稿导出」**，稿子还原成刚转写出来的样子

## 边听边改 · 搜索替换

- **双击任意一句**（或点时间码）→ 从这句开始播原音，边听边改
- 那句是噪声或语气词？**把字清空再回车 = 删掉这一句**，导出的稿子里就没有了
- 顶部有个搜索框，输个错字按回车，**自动跳到下一处**；命中句会标灰底
- 同一个错字满篇都是？点搜索框右边的**「替」**，填上正确的词 →**「全部替换」**，一次改完；
  按 `Ctrl+Z` **整批退回**（几百句也是一次退完）。替换框**留空**＝把这几个字删掉，
  删完只剩标点的句子会整句去掉

**导出前会自动扫一遍**，只挑**根本没人说过的**东西：只剩标点的空壳句、把「（音乐）（掌声）」写进正文的行、
同一段被识别两遍（两句时间戳重叠才算）。

**句子长短、口吃、拖音、一个词连说三遍、绕回来又讲一遍，全都是原声，一个字都不提醒你改。**
这是言札的底线：稿子要能证明「他当时就是这么说的」。

**只是提醒，不改也能照样导出**；一句问题都没有时不弹窗，底部会显示「扫过一遍，没发现问题」。

改完不用重新导出草稿——`txt / md / Word / srt / vtt / json` 用的都是改后的文字。

## 术语表：错一次，以后都不用手改

同一个主播的人名、栏目名、书名、公司名，每一期都会错成同一个样子。
每期都去搜索框改一遍，改的其实是同一批词。

点右上角 **「术语表」**，弹出来是**左右两栏**，填就行：

| 转写里出现 | → | 改成 |
|---|---|---|
| 李蛋 | → | 李诞 |
| 阿里巴巴 | → | 阿里巴巴集团 |
| 嗯嗯 | → | （留空） |

- **不用敲箭头**（键盘上没有 `→`）——左栏打错的词，右栏打对的字，中间那个箭头是画给你看的
- **右栏留空 = 把这个词删掉**（口语里的「嗯嗯」「那个那个」就这么去掉）
- 左栏打完按回车跳到右栏，右栏按回车自动加一条；点每行右边的 `×` 删掉这一条
- 从别处复制一整行 `李蛋→李诞` 粘到左栏，会自动拆进两栏
- 默认**转完自动套用**，列表里会写「术语 3 处」；改错了 `Ctrl+Z` **整批退回**
- 更省事的写法：在稿子上用**「替」**改对之后，勾上替换条里的**「记住」**，这条替换就自动进术语表了，不用回弹窗再打一遍
- 不想自动改就去掉那个勾，之后在「导出」菜单里点 **「按术语表改一遍」**

术语表只做你自己声明的替换，软件不会自己猜哪个字该改。

## 读音校对：只写对的，软件自己找错的

术语表的短板是**你得先知道它错成什么样**。可现实是你只知道"张小燕"这三个字怎么写，
不知道怎么被听成了"张晓燕"还是"张小艳"，也就没法填左栏。

点右上角 **「读音校对」**，这次**只写正确的写法**，一行一个：

```
张小燕
同济路
曾国藩
阿里巴巴集团
```

点「看看会改哪儿」，软件把稿子里所有读音对得上、字却不一样的地方找出来，一条条列给你：

```
第 3 句 · 同音 · 张小燕
张晓燕 → 张小燕
他说，张小燕明天到。
```

- **默认全勾**，把不想改的勾掉，再点「改勾选的这些」
- 改完一次 `Ctrl+Z` 整批退回，跟术语表一样
- 拿不准写哪些？点 **「从这份稿子里挑几个」**，软件会把反复出现、又不像常用词的片段列出来给你挑
- 多音字（曾、长、重这类）可以在词后面写拼音钉死：`曾国藩 zeng1 guo2 fan1`
- 已知错法的，也可以用别名写法：`张小燕 张晓燕 张小艳`

**它能改什么、不能改什么**（这点务必看清）：

| 情况 | 能不能改 | 说明 |
|---|---|---|
| 同音换字（张小燕→张晓燕） | 能 | 拼音完全一致，最可靠 |
| 近音换字（同济→桶吉、法律→发律） | 能 | 平翘舌、前后鼻音、l/n、f/h 都算近音 |
| 多字、漏字、词语顺序变了 | **不能** | 只做等长换字，字数对不上就不动 |
| 语义写错但读音也对（"守法"其实是"犯法"） | **不能** | 软件不猜意思，这种必须人来判断 |

它**只换字，不删字、不加字、不改句子结构**。所以改完的稿子仍然和录音逐句对得上，
这是它和外面那些"AI 润色"最大的区别——那些工具会把你的口语洗成书面语，
客户回头对音频就对不上了。

## 稿子不会丢

转完、改完，程序都会在本机存一份草稿。**改到一半直接关程序也不丢。**

- 下次打开，左栏出现「有 N 份没导出的稿子」，点一下就能接着改
- 草稿存在 `%LOCALAPPDATA%\YanZha\drafts`，**不上传、也不放进你的源文件夹**
- 导出过的稿子不再提醒；也可以在那份列表里点「删」自己清掉
- 源文件被移走了也能打开草稿——只是不能听原音、不能重跑分人

## 区分说话人

多人播客、访谈、对谈，勾上左下角的 **「区分说话人」**，
稿子会按人分段，标成「说话人 1 / 2 / 3 …」。

- **单人录音勾了也没关系**：只分出一个人时，标注会自动去掉，
  导出的就是干干净净的稿子，多花的只是几十秒分析时间
- 默认是开着的；确定是单人朗读、讲座，关掉更快
- 分几人不影响文字本身，只影响分段和标注
- 左下角 **「人数」** 默认自动。自动分人最常出的错是「明明四五个人，只分出两个」——远场录音里不同人的声纹会互相靠拢，硬阈值一裁就裁掉了。你清楚知道自己录的是几个人，就选上（1 到 6 人，**1 就是单人**），**按人数硬分，比任何自动判据都准**。
  自动分出 4 人以上时，稿子上方会直接问「这段其实几个人」，点「只有 1 个人」或「是 2 人」就重分，不用自己去找那个下拉框
- 分人的取舍是**宁可多分一个人，也不把两个人糊成一个**：糊在一起改不回来，重跑一遍还是糊的；多出来的人点一下就能改名
- 声音重叠、抢话、笑声多的时候，分人仍然可能有偏差，这是这类技术的通病；这时指定人数比自动稳得多

## 导出的八种格式

| 格式 | 用途 |
|---|---|
| **纯文本 .txt** | 按段落整理好的稿子，直接复制到别处 |
| **Markdown .md** | 带标题，适合放进笔记软件 |
| **Word .docx** | 能直接打开改，交给别人也方便 |
| **字幕 .srt** | 每一句带起止时间，导入剪映、Premiere、B 站；一句太长会自动折成两行，屏幕不溢 |
| **字幕 .vtt** | 网页播放器、YouTube 用的字幕格式；同样自动折行 |
| **带时间戳 .txt** | 每行前面有 `[00:12:34]`，方便回听核对 |
| **结构化 .json** | 每句的起止时间、文字、说话人，给程序或脚本用 |
| **校对稿 .txt** | 一行一句、行首带编号，专门拿去外面改，改完能粘回来（见下） |

**想把稿子拿出去改？** 点「导出 → 校对稿」存一个 txt，一行一句、行首是编号。
拿给任何工具改（本程序不联网，稿子出不出这台电脑由你决定），改完点「导出 → 粘贴改好的稿子…」，
把整篇贴进去：按编号逐句落回，**时间戳和说话人都留着**，一次 `Ctrl+Z` 全退回。
编号弄丢的那几行会跳过并告诉你，其余照常回填；说话人那一列改了不生效，要改名到稿子左边点「改名」。

**一次转了一批文件，不用一份一份导**：点「导出」→**「全部导出到文件夹…」**，
选一个文件夹，所有转好的稿子按同一种格式一起写进去。撞上同名文件不会覆盖，自动加 `-2`。

## 关于隐私

- 声音**只在这台电脑上处理**，一个字节都不上传
- 程序里没有任何联网代码，不上报、不统计、不检查更新
- 不装服务、不写注册表、不改系统设置
- 断网也能正常用——你可以自己拔掉网线试试
- **草稿和日志也只在本机**：`%LOCALAPPDATA%\YanZha\`（`drafts\` 是没导出的稿子，`yanzha.log` 是排查用的日志，可以随时删）

## 常见问题

**转出来的字有错怎么办？**
先看是不是录音质量问题（远场、回声、背景音重）。稿子可以直接编辑，遇到错字改掉就行。人名、数字、专业词最容易错，重要内容请人工核对。

**能转哪些语言？**
中文、English、日本語、한국어、粤语，不用手动选，模型自己判断语种；一段里中英混说也认。
普通话最准。四川话、天津话这类方言能认出大意，但不保证每个字都对。

**中英混着说呢？**
可以。英文会保留空格，和中文分开。

**为什么这么快？**
识别模型就在本地，用的是 CPU，不是云。你的电脑几核它就用几分力。

**文件特别大（两小时以上）？**
可以转，只是要多等一会儿。进度条是实时的，随时能停。

**要不要显卡？**
不要。纯 CPU，核显也能跑。

**出错了我该做什么？**
日志在 `%LOCALAPPDATA%\YanZha\yanzha.log`，把它发给作者就能定位问题。

**改了「区分说话人」的勾选，要重新转一遍吗？**
不用重转。识别结果会留着，只重跑分人那一步，几十秒就好。

**改了勾选后点「开始转写」没反应？**
已经转好、参数又没变的文件不会重复跑。换勾选或者换文件才会动。
